# AR-Waveguide-Grating-Pitch-Tolerance
Analytical simulations using my released Python GUI tools to study how grating pitch errors affect RGB diffraction angles and TIR conditions in AR waveguide input couplers. This project combines k-space analysis and pitch tolerance sweeps to connect optical design with fabrication specifications


【Grating Pitch Error and Optical Response in AR Waveguides】

I developed this project to connect optical design with fabrication requirements by studying how grating pitch errors affect RGB diffraction angles and total internal reflection (TIR).

The analytical simulations use my released Python GUI tools for k-space analysis and pitch tolerance evaluation. They assess directional feasibility, not diffraction efficiency.

See the accompanying presentation for the methods, results, and engineering implications.
